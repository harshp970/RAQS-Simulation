# RAQS Simulation Reproduction

This script runs a reproducible, synthetic evaluation of the RAQS adaptive question-tier policy and creates four publication-style figures. It does not run the HireMind.AI web application or call its services; the architecture figure is an illustration generated by the script.

## Requirements

- Python 3.9 or newer
- NumPy
- Matplotlib

Install the Python packages with:

```bash
python -m pip install numpy matplotlib
```

## Run

Run the script from the directory where you want the output folder to be created:

```bash
python raqs_simulation_repro.py
```

The script writes output under the relative path `artifacts/file_generation/ttl=63d/intermediate/`. Create or use a writable working directory. To keep results in a dedicated folder, copy the script there and run it from that folder.

## What the simulation does

Each simulated interview has six turns. Scores are mapped to three target tiers using these bands:

| Score | Tier |
| --- | --- |
| Below 60 | 1 (entry) |
| 60 to below 80 | 2 (mid) |
| 80 to 100 | 3 (high) |

The RAQS policy starts at tier 2 by default and adjusts the next turn's tier from the current score: below 60 lowers the tier by one, 60–79 keeps it, and 80 or above raises it. The tier is bounded from 1 to 3. It is compared with a fixed schedule (`1, 1, 2, 3, 3, 3`) and a randomly selected tier baseline. The script also calculates a smoothed proficiency estimate, initialized at 0.50, with `alpha` controlling how much each new score affects that estimate.

The experiments are:

1. **Deterministic profiles:** Four six-score profiles (Novice, Intermediate, Advanced, and Mixed) are run through RAQS and the fixed schedule.
2. **Five-seed Monte Carlo at σ=8:** Four cohorts are simulated with Gaussian score noise, clipped to 0–100. Each seed runs 200 trials per cohort and compares RAQS, fixed, and random policies.
3. **Noise sweep:** The three policies are compared at σ values 4, 8, 12, and 16.
4. **Ablation:** RAQS is evaluated with initial tier 1 or 2 and `alpha` values 0.2, 0.4, 0.6, and 0.8 on three stationary cohorts.
5. **Alpha sensitivity figure:** Final proficiency-estimate RMSE is plotted for `alpha` values 0.2 through 0.9 under σ values 4, 8, 12, and 16.

## Metrics

- **Tier MAE:** Mean absolute difference between selected and target tier, evaluated on turns 2–6. Lower is better.
- **Exact match:** Percentage of evaluated turns where selected tier equals target tier.
- **Over-challenge (OC):** Percentage of evaluated turns where selected tier is above the target tier.
- **Proficiency RMSE:** Root mean squared difference between the final smoothed estimate and the cohort's underlying mean score (normalized to 0–1).
- **± values:** For Monte Carlo and sweep results, the displayed MAE variation is the sample standard deviation across the five seed-level means. This is not a confidence interval.

The first turn is excluded from tier MAE, exact-match, and over-challenge metrics because the first question is selected before observing a score.

## Reproducibility notes

The experiment uses Python's `random.Random` with seeds `42`, `101`, `202`, `303`, and `404`. The simulation is synthetic: scores are drawn from specified cohort means and Gaussian noise, rather than collected from real interviews. The numerical results therefore describe this simulation setup and should not be interpreted as evidence of real-world hiring performance. The Python and library versions are not pinned by the script, so exact cross-version reproduction may vary.
